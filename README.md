# استوديو الديكور

موقع لعرض وبيع تصميمات داخلية (شقق، فيلات، غرف، جيمنج) ولوجوهات، اتعملت بالـ AI، مع نظام طلبات وتقييمات مربوط بـ Supabase.

**اللينك اللايف:** https://decor-studio-site-13d6a.web.app/

---

## المميزات

- معرض تصميمات بفلاتر (فيلات / شقق كاملة / غرف مفردة / جيمنج ولوجوهات)
- كارد تفاصيل بأنيميشن يفتح من نص الشاشة لما تدوس على أي تصميم
- سكشن "اختار لونك" بيشرح طريقة العمل (الفكرة → تصميم مبدئي → تنفيذ)
- سكشن خامات بتأثير كروت مروحية (Fan Cards)
- Scroll reveal — السكاشن بتظهر بالتدريج وانت بتسكرول
- سكشن ريفيوهات (فاضي لحد ما توصل أول تقييمات حقيقية من عملاء)
- تكامل جاهز مع Supabase (قاعدة بيانات + Row Level Security)
- تصميم متجاوب بالكامل (موبايل / تابلت / ديسكتوب)، RTL بالعربي

---

## الستاك التقني

- **Frontend:** HTML / CSS / Vanilla JS (من غير أي framework)
- **Backend / Database:** [Supabase](https://supabase.com) — Postgres + Auth + Storage + Row Level Security
- **Hosting:** Firebase Hosting
- **الخطوط:** Markazi Text (سيريف) + Cairo (عربي) من Google Fonts
